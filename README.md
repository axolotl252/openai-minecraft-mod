# Client-Side Ai Bot for Minecraft
Credit to TerminalCalamity for providing the AutoSocial code that this mod is based on

## Setup

1. Be sure you have Fabric installed on Minecraft 1.21.6
2. Download Ollama from https://ollama.com and pull the ai model you wish to use (if choosing a cloud model, be sure to run it before using in the mod so you can sign in to Ollama from the terminal)
3. Download a copy of yt-dlp if you would like the model to be able to play sounds from YouTube (the executable, look it up on a search engine)
4. Make sure ffmpeg is installed and added to your path if you want the model to be able to play any sounds at all
5. If you would like to have the mod play sound through a VC mod, make sure you have VB-Cable installed, and set your mic to be the VB-Cable output.
6. Compile the mod and put both output jar files in the mods folder of your Minecraft instance
7. Run the Minecraft instance, and be sure to bind both the skip and reload config buttons in the keybinds setting in options
8. Open your .minecraft folder and navigate to config\autosocial\autosocial.yml
9. Now, modify the config file to point to your yt-dlp executable and change the system prompt to your desire (be sure to keep the notes that mention audio if you would like to be able to use it, and keep everything after "Keep your responses to 3 sentences or less")
10. Have fun with your new ai bot!
